EduDocs Portal is a full-stack web application that streamlines the process of requesting, 
tracking, and managing academic documents through a secure digital platform. It replaces
manual workflows with an efficient online system, providing students with a seamless request
experience and administrators with centralized request management.

Key Features
- Secure student and admin authentication using JWT
- Online academic document request submission
- Real-time request status tracking
- Student profile management
- Admin dashboard for reviewing and managing requests
- Responsive and user-friendly interface

Tech Stack
Frontend: React.js, Vite, JavaScript, CSS Modules
Backend: Node.js, Express.js
Database: MongoDB Atlas
Authentication: JWT

Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
